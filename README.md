## 🇬🇧 ENGLISH DETAILS

### 📌 Overview
**Khmer Video Clipper Pro** is an advanced AI-powered desktop and web application designed to automatically scan, analyze, transcribe, slice, and burn subtitles into Khmer short-form videos (TikTok, Reels, Shorts). It handles long-form videos (e.g., 53+ minute Dhamma sermons, podcasts, talks) and converts them into high-engagement vertical short clips with burned-in Khmer subtitles and custom titles.

### 🌟 Key Features

1. **Full-Length Video Coverage (53+ Minutes)**
   - Dynamically scans entire long-form videos without arbitrary time limits.
   - Automatically detects 12 to 15+ engaging viral segments across the full timeline.

2. **OpenAI Whisper STT (Khmer Speech-to-Text)**
   - Uses OpenAI Whisper `large-v3` / `small` with specialized Khmer Dhamma context prompts (`"ធម្មទេសនា ព្រះធម៌ ព្រះសង្ឃ កម្មផល..."`).
   - Generates precise timestamped `.srt` subtitles in Khmer script.

3. **Google Gemini 2.5 Flash Integration**
   - Integrates Google's latest `gemini-2.5-flash` model for instant highlight extraction, emotional hook scoring (85%-98%), and viral headline generation.

4. **100% FREE AI Mode ($0 Cost)**
   - Built-in dynamic Dhamma sermon storyline generator that operates without requiring API keys or payment.
   - Custom topic generator (e.g., user inputs `"រុក្ខបុផ្ផា"` or `"សីល៥"` to tailor clip highlights).

5. **FFmpeg Subtitle Burn-In & Auto Video Slicing**
   - Performs precision frame-accurate video trimming.
   - Automatically renders styled Khmer captions directly onto video frames.

6. **Standalone Windows Desktop Application (.exe)**
   - Packaged with PyWebView, PyInstaller, and FFmpeg as `Khmer_Video_Clipper_Pro.exe`.
   - Includes 1-Click Desktop Installer (`Create_Windows_Installer.bat`).
